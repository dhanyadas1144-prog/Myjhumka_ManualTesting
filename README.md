# OneTeamShopping – Manual Testing Project

## About the Project
OneTeamShopping is an e-commerce web application. This project focuses on manual testing to verify the functionality, usability, and reliability of the website.

## Application URL
https://oneteamshopping.netlify.app/

## Testing Scope
The following modules and functionalities are covered:

- Home Page
- Search Functionality
- Product Listing
- Product Sorting
- Add to Cart
- Cart Management
- Product Quantity
- Price Verification
- Checkout Process
- Promo Code Validation
- Order Placement

## Testing Activities
- Requirement Analysis
- Test Scenario Preparation
- Test Case Design
- Test Case Execution
- Positive and Negative Testing
- Functional Testing
- UI Testing
- Bug Identification and Reporting
- Regression Testing

## Testing Documentation
- Test Scenarios
- Test Cases
- Requirement Traceability Matrix (RTM)
- Bug Reports
- Test Execution Results

## Tools Used
- Microsoft Excel – Test Case Documentation
- Web Browser – Application Testing
- Manual Testing – Test Execution and Validation

## Project Objective
To identify functional defects, validate application requirements, and ensure the website provides a smooth and user-friendly shopping experience.

## Skills Gained
Manual Testing | Test Case Design | Functional Testing | Bug Reporting | RTM | Regression Testing
